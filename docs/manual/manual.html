1 · What's new

Twisted Song Mode adds the arrangement tools of Paula's Revenge to the Tracker's Song screen. The rest of the Tracker works exactly as in Polyend's Community Edition.

FeatureWhat it does
Song sectionsName the parts of a song (INTRO, DROP, BREAK…). Each section shows as a divider line in the song view.
Loop SectionLoop the section you're in. Move to another section while the song plays and the Tracker jumps there at the end of the current pattern.
Loop SelectionLoop any run of slots you highlight.
Clone In PlaceGive one slot its own copy of a pattern, so you can change it without changing every other place the pattern is used.
Linked variationsA copy that keeps following the original on every track you haven't changed.
Pattern namesName a pattern from the song view. It's the same name the pattern editor shows, so a name set in either place shows in both.
AkaizerThe classic Akaizer timestretch: as a Sample Editor effect, as a live Akaizer play mode for instruments, and as two FX commands (K Stretch, Y Cycle) that change it per step.
Block coloursColour-code the blocks in the song view with 8 colours (drums blue, bass red…). Colours move with blocks you copy.
Your projects stay safeSections, variation links and block colours are kept in a separate file inside the project. Stock Polyend firmware ignores that file, so it still opens your projects. It just won't show the sections or colours, or keep variations linked.

2 · Installing the firmware

Download

  1. Open the repository's Releases page and download TrackerPlus_Twisted_<version>.ptf from the latest release (for example TrackerPlus_Twisted_1.0.0.ptf). This manual is attached to the same release.
  2. Alternatively, open the Actions tab, choose the latest successful Build Tracker CE Firmware run and download the polyend-tracker-ce-firmware zip. The Tracker+ file inside is called TrackerPlus_CE_<commit>.ptf.

Flash

  1. Back up your SD card, or at least your Projects folder.
  2. Copy the .ptf file into the Firmware folder on the SD card. Keep a stock firmware file in the same folder so you can go back.
  3. Put the card in the Tracker+ and switch it on.
  4. Go to Config › Firmware › Firmware update, pick the Twisted file and confirm.
  5. Let the update finish. Don't switch off while it runs. The Tracker restarts on its own.
Going back to stockFlash the stock Polyend .ptf the same way. The update loader is separate from the firmware, so you can always re-flash, even if a build won't start.
Testing statusThis firmware builds cleanly for all three Trackers, but it is new. Try it on a copy of a project before you trust it with a gig set.

Soloing a track

In the block grid, move the cursor onto a block of the track you want to hear on its own and press F8 (Solo Track). Every other track is muted, sample and MIDI tracks alike, and their blocks turn dim. The F8 label shows ON.

  • Move to another track and press F8 to solo that one instead.
  • Press F8 on the soloed track, or from the song list, to end the solo. The tracks go back to the mutes they had before.
  • It works while the song plays and doesn't need REC.
  • If you change mutes elsewhere during a solo (mixer, pattern editor), ending the solo still restores the mutes from before it.

Naming patterns

Select a slot and press F2 (Pattern Name). Type the name with the pads, exactly as for a section, and press F8 (Save). This doesn't need REC.

  • It's the pattern's own name, the same one the pattern editor uses. Every slot that plays the pattern shows the new name.
  • You can still name a pattern in the pattern editor: press F8 (More) until the buttons show Pattern Name, then press F1. The song view shows that name too.
  • Up to 30 characters. Saving an empty name clears it.

4 · Song sections

A section is a named part of the song. It starts at a slot you choose and runs until the next section starts. Any slots before the first section count as one unnamed section.

Name a section

  1. Press Rec so edit mode is on.
  2. Select the first slot of the part in the song list.
  3. Press Insert for the tools, then F1 (Section Name).
  4. Type the name, the same way you name a pattern (details below).
  5. Press F8 (Save). F7 (Cancel) leaves without changing anything.

Typing a name

PadsType the letter shown on the on-screen keyboard.
ArrowsMove around the on-screen keyboard.
F1 or InsertType the highlighted key.
DeleteBackspace.
F7 / F8Cancel / Save.

How sections look

  • A red line runs across the song blocks at the top of each section.
  • The section's first slot in the list starts with the section name, for example DROP: AMEN CHOP.

Renaming and removing

  • To rename a section, select its first slot and press F1 again. The current name is filled in for you.
  • To remove a section, select any slot in it and press Shift + F1. The slots stay; they join the section above.
  • Saving an empty name also removes the section.

Editing the song

Dividers move with the music. If you add or delete slots, the sections after that point shift with them. Deleting the first slot of a section moves the divider to the slot that takes its place.

LimitsUp to 32 sections per song. Names can be up to 16 characters.

5 · Loop Section and live jumping

Loop Section keeps the song cycling around one part while you play over it, then lets you move to another part on the beat. This is the Paula's Revenge "jam between parts" workflow.

Start a section loop

  1. Select a slot in the part you want to loop.
  2. Press F3 (Loop Section). A message shows the section name and its slots.
  3. Start the song with Play. It plays through the section and goes back to its first slot instead of carrying on.

The looped slots get a red bar down their left edge, and the title bar shows Song LOOP: DROP. If the section has no name, the title shows the slot numbers instead.

Jump to another section while playing

With Loop Section on, you can move the selection while the song plays, even without REC.

  1. Use the arrows or the encoder to select a slot in a different section.
  2. That slot gets a green bar on its left edge: the jump is queued.
  3. When the current pattern ends, playback jumps to the selected slot and loops its section from then on.
  • You choose exactly where to land: pick the first slot of a section for a clean entry, or a later slot to come in part-way.
  • Moving the selection back into the playing section before the pattern ends cancels the jump.
  • While a section loop runs, the selection stays where you put it instead of following playback, so you can line up the next jump.

Stop looping

Press F3 again. The song carries on to the end as normal from wherever it is.

Starting playbackPlay (or Play Song on the normal song buttons) always starts the song from the selected slot, and clears any queued jump. If Loop Section is on, the loop moves to the section you started in.

6 · Loop Selection

Loop Selection loops any run of slots, whether or not they line up with your sections.

  1. Go to the block grid on the left (the arrows move between the grid and the list).
  2. Hold Shift and use the arrows to highlight the slots.
  3. Press F4 (Loop Selection). A message shows the slot numbers.
  • If you're in the song list instead of the grid, F4 loops just the selected slot.
  • If the song is playing outside the selection, it goes to the first selected slot when the current pattern ends.
  • The looped slots get the red bar, and the title shows LOOP: 5-8.
  • Press F4 again to stop.

Only one loop can be on at a time. Turning on Loop Selection replaces a section loop, and the other way round.

When loops switch off on their ownAdding or deleting a slot turns any loop off and clears a queued jump, because the slot numbers have changed. Turn the loop on again afterwards.
ExportingSong export always renders the song straight through once, from start to end. Loops and queued jumps are ignored while exporting.

7 · Clone in place

Normally a pattern used in several slots is the same pattern everywhere: change it once and every slot changes. Clone In Place gives one slot a separate copy.

  1. Press Rec.
  2. Select the slot in the song list.
  3. Press F5 (Clone In Place).

The Tracker copies the pattern into the next free pattern and points the slot at the copy. A message tells you the new pattern number, for example Slot 7 now plays pattern 23. The copy has the same name as the original.

The next free pattern is the lowest-numbered pattern that is empty, isn't used anywhere in the song, and isn't part of a variation.

TipClone a slot, then open it in the pattern editor to make a fill or a drop-out for that one bar without touching the main groove.

8 · Linked variations

A linked variation is a copy that keeps following the original. Change the drums in the original and the variation's drums change too, unless you've already changed the variation's drums yourself.

Make a variation

  1. Press Rec and select the slot.
  2. Press F6 (Make Variation).

As with Clone In Place, the slot now plays a new pattern. In the song list it is marked with a ~, for example ~AMEN CHOP.

How following works

Tracks you haven't touched follow the original. Whatever you write in the original appears in the variation.

Tracks you've changed belong to the variation. The first time you change a track in the variation, that track stops following, for good.

  • Changes count however you make them: in the pattern editor, or by pasting or deleting tracks in the Song screen.
  • The pattern length follows the original too, until you change the variation's length.
  • A variation can itself be the original of another variation. Changes pass down the chain.

When updates happen

A variation picks up changes when the original is saved to the workspace. That happens when you switch to another pattern, go to another screen, or the Tracker autosaves. So you'll see the change in the variation a moment after you leave the original.

If you're editing a variation when its original updates, your unsaved edits are saved first, so they stay yours and aren't overwritten.

Unlink a variation

Select its slot, press Rec, then Shift + F6 (Unlink Variation). It keeps its current notes and becomes an ordinary pattern. The ~ disappears.

ExampleMake three variations of your main jungle break for verse 2, verse 3 and the outro. Change only the snare track in each one. If you then tweak the kick or hats in the original, all three variations get the new kick and hats, but each keeps its own snare.

9 · Block colours

Colour-code the blocks in the song view so you can see what's what at a glance: for example drums blue, bass red, pads purple. Colours are only a visual tag; they never change the sound.

Colour some blocks

  1. In the block grid on the left, select the blocks: hold Shift and use the arrows to cover the slots and tracks you want. To colour a whole column (a track all through the song), select from the first slot to the last.
  2. Press Insert for the tools, then F7 (Block Colour).
  3. The eight buttons turn into the colours. Press the one you want.

The colour picker: F1 to F8 are the colours. On the Tracker each name is written in big text in its own colour (lighter shades for Blue and Purple, so they read clearly on the dark screen).

  • A message confirms the colour and how many blocks changed, and the tools come back.
  • Delete in the picker removes the colour from the selected blocks. Insert closes the picker without changing anything.
  • If you're in the song list instead of the grid, the colour goes on every track of the selected slot.
  • Colouring doesn't need REC, so you can do it while the song plays.

How colours behave

  • A colour belongs to the track of the pattern, not to the slot. If pattern 4 plays in five slots, colouring its drum track in one slot colours it in all five, because it's the same pattern.
  • Copy a block and the colour moves with it. Copying and pasting blocks in the song screen copies the colour along with the notes, onto whichever track you paste to.
  • Clone In Place and Make Variation copy all the colours to the new pattern.
  • Deleting blocks in the song screen removes their colour along with the notes.
  • Only blocks with notes show a colour. A muted track shows a darker version of its colour.

10 · Akaizer timestretch (Sample Editor)

Akaizer is the timestretch behind a generation of jungle and drum & bass breaks: the same engine as Twisted Timestretch, a line-for-line port of Akaizer v1.2. On the Tracker it's an effect in the Sample Editor, next to the built-in timestretches.

Use it

  1. Open the Sample Editor on the instrument.
  2. Select the part to stretch, or leave the whole sample selected.
  3. Choose Akaizer in the effect list (after Fade Out, before any plugin effects).
  4. Set the five settings below with the encoder.
  5. Press Preview to hear it, then Apply to keep it. Undo works as with any effect.

Settings

SettingRangeWhat it does
Stretch25 – 2000 %The new length as a percentage of the original. 200 % doubles the length at the same pitch.
Cycle Len20 – 2000 smpGrain size: each grain is twice this long. Short cycles sound grainy and metallic, long ones smoother and more echoey.
Cycle FreqAuto,
20 – 2050 cps		How often grains are laid down. Auto links it to the cycle length (41000 ÷ Cycle Len), as the original does until you set it by hand. Turn below 20 to get back to Auto.
Pitch−24 – +24 stSampler-style repitch before the stretch. The final length stays at Stretch, so "pitch up, stretch back to length" is one move.
Loop BPMOff,
40 – 300		The tempo the loop is at now. When set, the loop is stretched to the project tempo and the Stretch setting is ignored. A 136 BPM break with the project at 170 BPM comes out 80 % long.
  • Audio outside the selection is kept; only the selection changes length.
  • Stereo samples are processed the way the original processes stereo files, quirks included. Mono samples stay mono.
  • The result can be up to about 44 seconds. Anything longer shows Stretched sample is too long!
Faithful to the originalThe engine was checked sample for sample against Twisted Timestretch's reference renders of Akaizer, and against its pitch engine. Same settings, same sound.

11 · Akaizer play mode and FX commands

The Akaizer play mode stretches an instrument live, every time it plays. Change the tempo or the settings and the next note follows, with no re-render. Two FX commands change the stretch and the grain size step by step in a pattern.

Set up an instrument

  1. Open the instrument's Sample Playback screen.
  2. In the play mode list (far right), choose Akaizer, at the bottom after Granular.
  3. Set Start and End as for 1-Shot. The part between them is what gets stretched.
  4. Set the Akaizer settings on F3 and F4 with the encoder or the arrows.

  • Pitch works like the original's "pitch, then stretch back to length". Play the instrument higher or lower, or use Tune, Glide and the pitch FX: the pitch changes but the length stays at the stretch.
  • Reset a setting to its default the same way as on the other modes (it resets the one shown: Stretch 100 %, Loop BPM Off, Cycle Len 800, Cycle Freq Auto).
  • The rest of the instrument (envelopes, filter, FX sends) works as normal.

FX commands

FXValueDoes
K Akaizer Stretch25 – 255Stretch in percent while the effect lasts. K100 = original length, K200 = twice as long. It overrides both Stretch and Loop BPM.
Y Akaizer Cycle2 – 200Cycle Len ÷ 10 while the effect lasts. Y80 = 800 samples, Y8 = 80 samples (very grainy).
  • They only affect instruments in Akaizer mode, and act on the note that's playing too: put Y on the steps after a long note to change its grain as it plays.
  • Like the other FX, an effect lasts until the track gets a different FX in that slot, or the effect ends.
  • With both FX slots set to the same command, the first slot wins.
Live vs. the Sample EditorThe live mode follows the original's maths (grain spacing, rounding, length), and on the desktop came within about 50–60 dB of the offline Akaizer. It isn't sample-for-sample identical. Stereo is stretched per channel, without the original's stereo-file quirks. At most 8 grains overlap: very dense settings (long cycles with a high Cycle Freq) keep the newest grains. For the exact classic result, use the Sample Editor's Akaizer and play the rendered sample.

12 · Projects, saving and compatibility

  • Sections, variation links and block colours are saved in the file patterns/twistedSong inside each project, next to the pattern files.
  • They're saved and opened with the project as usual. You don't need to do anything extra.
  • A new or older project with no twistedSong file simply starts with no sections, variations or colours. Projects saved before block colours existed open fine and gain colours the next time they're saved.

Opening a project on stock firmware

Stock firmware ignores twistedSong, so the project opens and plays normally.

  • Sections and block colours aren't shown.
  • Instruments in Akaizer play mode don't play on stock firmware (it doesn't know the mode), and K / Y FX are ignored. Switch an instrument to another mode, or render it with the Sample Editor's Akaizer, before sharing.
  • Variations play as ordinary patterns with the notes they had when last saved.
  • Edits made on stock firmware don't update variations. When you're back on Twisted firmware, the links resume from the next time an original is saved.
Sharing projectsAnyone on stock firmware can open your projects; they just won't see the sections or colours, or keep variations linked.

13 · Messages and troubleshooting

Message or problemMeaning / what to do
Press REC to edit the songThat tool changes the song. Turn on edit mode with Rec first.
No free pattern leftEvery pattern is used, so Clone In Place or Make Variation has nowhere to copy to. Clear a pattern you don't need.
Too many sectionsThe song already has 32 sections. Remove one first.
No section hereThe selected slot is before the first section, so there's no divider to remove.
Not a linked variationUnlink only works on slots marked with ~.
The loop stopped by itselfYou added or deleted a slot. Turn the loop on again.
The selection won't move while playingLive selection only works with Loop Section on, or with REC on.
A variation didn't updateThe original hasn't been saved yet. Switch pattern or screen, then check again. If you changed that track in the variation, it no longer follows by design.
Stretched sample is too long!The Akaizer result would be over about 44 seconds. Lower Stretch, or stretch a shorter selection.
A pattern name doesn't show in the pattern editor titleThe title shows pattern info instead of the name when Pattern info is turned on in the Tracker's Config.
Granular settings reset after trying AkaizerAkaizer keeps its settings where Granular keeps its own. After you've edited Akaizer settings, going back to Granular starts it from the defaults.
K / Y FX do nothingThey only act on instruments in Akaizer play mode.
A block I coloured shows no colourOnly blocks with notes are coloured. Add notes to that track and the colour appears.
Colouring one slot coloured others tooThose slots play the same pattern. Use Clone In Place (F5) first to give the slot its own pattern.
Insert doesn't open the toolsCheck that you're running the Twisted firmware and are on the Song screen. The Tracker Mini has no song tools.

Found a bug? Open an issue on the repository with the steps that cause it.
